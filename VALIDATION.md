## Before enabling broadly

Perform separately in `_classic_beta_` and `_forever_` once each can be played. The launch client being preinstalled is not evidence of a successful login or gameplay test.

1. Start with all original addons available and ForeverSuite features off. Confirm `/fs`, search, scrolling, checkboxes, the Opt panel, Escape, moving the settings windows, and the report's copy box. Test at the user's UI scale and resolution.
2. Choose a small feature group; disable the conflicting reference addon for that test and reload. Verify conflict status changes. Do not remove its saved settings.
3. Test stackable/nonstackable/uncached item tooltips; equipment with different actual item levels; repeated hovering; comparison tooltips; combat entry/exit. Ensure no duplicate suite lines or Lua errors.
4. Test spell tooltips (ranked and unranked), currency tooltips, creature/vehicle/player/pet unit tooltips and an item with bank copies. Verify NPC IDs against a known creature and that bank counting only changes after the bank is opened.
5. Test repair with enough/insufficient funds and below/above the cap; Shift override; merchant with no repair; junk with an explicitly marked item. Verify actual buyback behavior and do not assume unlimited recovery.
6. Test quest reading with Shift, zero/one/multiple choice rewards, a quest requiring money, autoaccept quests, and combat transitions. Only the documented zero-choice free hand-in is automated.
7. With the dialog features enabled, test Space jumping and normal bindings when no dialog is open, accepting a quest by key, advancing quest text, a quest with reward choices (key must not complete it), reward digits 1-6 (selection must not turn in), popup confirmations, chat typing and edit boxes, and combat entry/exit. Confirm `/fs report` shows no blocked actions. If the key hint is misplaced at the user's scale, turn it off and report the frame.
8. Test character and inspect overlays on empty slots, two-hand weapons, ranged/relic slots, item level changes while the panel is open, inspect of a party member, target changes during inspect, combat entry/exit, and both text positions and the size range.
9. Toggle interface settings individually. Confirm visual effect, restore behavior and another addon's external changes. Turn features off before uninstalling. Test normal logout/restart persistence independently in both clients.
10. Capture `/fs report` and actual errors through the existing BugGrabber/BugSack setup. Do not suppress Lua errors as a substitute for fixing them.
11. Record client build, feature IDs, options used, locale, UI mode, outcome, taint/error evidence and performance observations. No character/account data is required for a public issue.

Combat lockdown, client secrets, keyboard focus and propagation, real item-cache event ordering, Lua taint, gamepad navigation and secure frame behavior are not emulated by the tests. Settings rendering, memory/CPU performance and encounter correctness remain unmeasured in game.
