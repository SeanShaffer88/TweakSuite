# TweakSuite — store description

## Short (one line)
227 optional quality-of-life tweaks for WoW Forever in one searchable settings window. Everything starts off.

## Long

**TweakSuite** gathers the small fixes and conveniences you would normally collect from a dozen addons into one place, built for World of Warcraft: Forever. Every tweak is its own switch, every switch starts **off**, and each one tells you exactly what it does before you turn it on.

**What you get**
- **Automation** — repairs within a gold cap you choose, junk selling with rules and a preview, quest accept and free turn-in with exception lists, invite, duel, summon and resurrect rules. Hold Shift to skip any of it; nothing automatic runs in combat.
- **Dialogs** — press a key to accept or continue quests, number keys for gossip lines and quest rewards (rewards are only selected; you still confirm). Popup confirmations are never touched and options that cost money are never chosen.
- **Tooltips** — item level, item and spell IDs, stack size, vendor price, counts in bags and bank, upgrade comparison, spell damage per second, minute and mana, class colours, border colours, a fixed screen-corner position, and an option to hide tooltips during combat.
- **Item overlays** — item levels and durability on character, inspect, bag, bank, loot and roll frames, missing-enchant and empty-socket markers, average item level.
- **Windows** — Shift-drag Blizzard windows, resize them, keep them on screen, save layout sets.
- **Interface, nameplates, chat, maps and more** — over 80 interface toggles, nameplate and overhead-name options, chat history, timestamps and a whisper window, map coordinates, flight timers, hazard warnings you define, cursor ring and more.

**Built to be trusted**
- Every setting has a **?** with its effect, default, what switching it off restores, combat behaviour and any overlapping addon.
- When it changes a client setting, it remembers your previous value and restores it when you switch the tweak off.
- If an addon covering the same feature is loaded, the matching tweak waits instead of fighting it.
- `/ts report` gives a copyable status and error report. `/ts pause` stops everything for the session.
- No network access, no external code, no always-running polling loop.

**Getting started:** install, enable TweakSuite on the AddOns screen, type `/ts`, and switch on only what you want.

**Upgrading from ForeverSuite:** TweakSuite is the same project under a new name. Run `/fs reset` in ForeverSuite before removing it; settings start fresh.

Preview release: the tweaks are covered by 190 automated tests, but in-game verification on Forever is still in progress. Keep any addon you depend on until its TweakSuite replacement has been tested in your setup.
