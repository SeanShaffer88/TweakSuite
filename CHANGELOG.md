# Changelog

All notable changes to TweakSuite (formerly ForeverSuite). Versions follow semantic versioning; `alpha` builds have passed the automated checks but not in-game verification.

## 0.3.0-alpha.2 — 2026-10-22

### Added
- **Minimap button** with the TweakSuite icon: left-click opens or closes TweakSuite, right-click opens its Options page, drag moves it around the minimap edge (round or square minimaps). Shown by default; hide it with **Show minimap button** in Options > AddOns > TweakSuite or `/ts button`. The minimap button collection feature leaves it alone.
- Options > AddOns > TweakSuite page now shows the icon, version and author, the minimap button checkbox and the Open TweakSuite button.
- Six tests (196 total) for the minimap button, its saved settings, the Options checkbox and standalone window behaviour.

### Changed
- **TweakSuite windows are standalone.** Closing the game Options panel no longer closes them. Escape closes the topmost TweakSuite window on its own; during combat, when keyboard handling is restricted, Escape falls back to Blizzard's normal panel handling.

## 0.3.0-alpha.1 — 2026-10-22

### Changed
- **Renamed ForeverSuite to TweakSuite.** Addon folder, TOC files, settings store (`TweakSuiteDB`), frame names and messages all use the new name. The chat command is now `/ts` (also `/tweaksuite`).
- **Relicensed under the GNU GPL v3.0 or later**, author Malikor. Every Lua and tool source carries the GPL SPDX header; `LICENSE` holds the full GPLv3 text.
- Settings and diagnostic windows show the TweakSuite icon beside their titles.

### Added
- Addon icon (`Media/Icon.tga`, shown on the AddOns screen through `IconTexture`) and a project logo (`media/logo.png`), both generated by TweakSuite and credited in `CREDITS.md`.
- `CHANGELOG.md`, `DESCRIPTION.md`, `AUDIT.md` and `CREDITS.md`.
- Upgrade guard: if the old ForeverSuite addon is still loaded, every TweakSuite feature is blocked with the status *conflict: ForeverSuite (previous name of this addon)*, so no tweak runs twice.
- Four tests (190 total): compatibility shims never touch the global table, quest turn-in reads the money requirement from the NPC dialog, the previous-name guard, and the settings icon.

### Fixed
- **Compatibility shims no longer write to the global table.** Older-client functions that Forever removed (`GetContainerNumSlots`, `GetContainerItemInfo`, `UnitAura`, `GetQuestLogTitle`, `GetGossipOptions` and others) were installed as globals, which other addons use to detect older clients and some of which they expect in their original return shape. They now live in a private table and each module aliases only the names it uses.
- **"Turn in quests without reward choices" could ignore a money requirement.** On Forever the old `GetQuestRequiredMoney` global is gone, and its replacement shim read the quest *log* selection instead of the quest being turned in. It now uses `GetQuestMoneyToGet`, which the Forever client provides for the open quest dialog.
- Provenance check now allows TweakSuite's own credited artwork in `TweakSuite/Media` and `media/` and requires `CREDITS.md` and `CHANGELOG.md`.

### Upgrade notes
Settings do not carry over from ForeverSuite. Before removing ForeverSuite, run `/fs reset` in game so it restores the client settings it changed.
